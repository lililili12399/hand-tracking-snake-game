1. Use a frame with the participant's permission, or record a new demo without an identifiable face or private background.
2. Check the frame for names, notifications, account details, and room/location clues.
3. Save the approved image in this folder, for example as `gameplay.png`.
4. Add the approved image to the main README only after the file exists.
